2026-10-04（北京时间）。本阶段优先处理复杂题有解析却缺点线、错误左右支推导及重复自动标签。沿用现有 Web、桌面、手机与离线缓存架构，不重写项目，不接新服务，不增加题库答案查表。

## 原因与已落实改动

1. 未标点名的“左焦点为坐标”旧输入层没有提取；无名过点又默认占用 P，和后面定义的派生交点冲突。增加描述型焦点解析、左右位置校验和冲突时的空闲过点名称。
2. 上轮2023全国二卷21真实回复的 scene 包含未知 dynamic 点引用及不支持的 vertical 构造，按安全协议整图拒绝；它还误排除竖直弦、误判两个交点同为第二象限。保留拒绝机制与原步骤，增加独立顶点割线模型，不执行模型代码或猜测任意标签。
3. 模型参数为任意有效 a、b、u（u<-a），联立 x=my+u 与双曲线，用韦达和两点式消元得到 X=a²/u。证明包括 D<0、交点异号、消元因子非零、m=0竖直弦及渐近方向排除。识别只接受已覆盖目标，附加目标、错误顶点对应、错误分支、同名坐标冲突不会被悄悄忽略。
4. 图形使用 point_on、line、second_intersection、intersection 的现有原生依赖。M=(-a cosh t,b sinh t)，t>ln(-u/a)，N取同一弦的另一交点，再连顶点求P；拖动投影、合法范围、刷新恢复和无限制移动沿用当前系统。仅完整独立覆盖时对齐文字、假设与图形，原AI步骤保留。
5. 下标线名审计把MA_1截成MA，导致正确图仍显示缺图。现在两个端点均保留完整数值下标和撇号；原图已被独立模型替换后，将旧警告留在model_scene_warnings，不当作当前scene警告。当前图仍独立审计。
6. 自动直线交点若与可见命名点在世界坐标上相等，复用其名字、不画第二个J标签。比较阈值不以屏幕距离判断；用户同坐标别名、相邻不同点、未知交点保留，隐藏点不吞掉可见直线的交点。
