# 0.62.0 验证记录

2026-10-11（北京时间）。轻量动态画板的第一阶段，不替换数学引擎、不修改云端策略。

dist/index.html 新增默认关闭的对象管理弹窗，不占画布尺寸；dist/construction-board.js 提供按名称/类型搜索、选择和显隐，展示依赖、无效原因与当前小问状态。显隐共用原事务与撤销栈，不删除关系或运动范围。选中状态和列表同步，聚焦控件重绘后恢复焦点；列表文本不执行 HTML。普通追加点、线、圆和圆锥曲线使用选中色。

tests/inverse_locus_browser_smoke.cjs 在明确标识的协议图稿中验证隐藏点选中、显隐、范围保留、撤销重做、搜索空结果与320像素布局；保留原有2025全国一卷18题及受限轨迹回归。与 additive_conic_snap 两组浏览器通过。

此阶段不是完整 GeoGebra 替代：主曲线、题设坐标、多边形仍由原入口管理；属性编辑仍在原检查栏，未统一为移动端就地编辑。没有新增通用解题能力。完整回归、线上页面和安装包另行验收。
