# 0.54.0 验证记录

2026-10-05（北京时间）。沿用现有Web、桌面、手机和离线架构，不重写项目、不迁移云服务、不改访问策略，不增加题库答案查表。

## 原因与改动

小问解析器已正确保存父问条件及201/202编号。2025全国一卷18自由输入失败的主因是曲线参数反推缺少“离心率+相邻顶点间距”，后续反演、轨迹和最值尚无独立数学模型；不是该题条件不足。

新增dist/inverse-locus.js：联立b²=(1−e²)a²及a²+b²=L²；反演系数ρ/D>0，R=A+ρ(P−A)/D；在m≠0条件下等价消去斜率得到轨迹圆，并检查逆向充分性。以三角不等式和闭区间二次函数求全局距离界，逐一检查取等与被排除的轴交点。任意参数和点名从题面读取；有界语法外的额外约束或目标不被默默忽略。

场景使用现有point_on、inverse、ray、line、segment原生依赖，不执行模型代码。坐标问为平面驱动、最值问为轨迹圆驱动；M绑定椭圆，各问保留独立位置，关闭无限制移动时恢复题设。最大距离读数、两组定位和高亮共用原题参数；手机图像栏增加默认折叠读数。排除的轴交点以空心标记显示。

仅独立完整覆盖时对齐云回复的最终答案、策略和画板；保留model_answer、model_steps、model_scene及旧警告。不把模型原先未解出的小问宣称为纯模型成功。

## 边界与下一阶段

目前限原点中心、水平长轴、已覆盖语法的上下顶点与右顶点、正长度乘积、非y轴动点及比例斜率构型。一般平移旋转、多重附加条件、不同表达和其它反演构型仍需继续扩展。最大值若仅在排除点取到，显示上确界而不是伪造最大值；超出稳定数值范围不构造图形。

下一阶段优先处理2022全国一卷21含参分母、对称割线，以及同构题目的不同表达。Cloudflare国内直连限制未在本轮解决；离线查看不等于离线调用云模型。
