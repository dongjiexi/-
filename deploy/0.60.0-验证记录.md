# 0.60.0 验证记录

2026-10-09（北京时间）。本阶段合并运动参数提前校验、受限轨迹分段及开闭端点标记。

dist/motion-domain.js在fit前拒绝异常参数；periodicGeometry针对圆、轴向椭圆用解析边界切分参数区间，再采样绘制合法光滑弧。边界来自已有范围，不从采样猜测轨迹方程。支持参数、跨周弧段、坐标、象限、排除轴和排除点，处理空集、孤立点和整周等价端点。

dist/index.html仅为role=derived_locus且有唯一当前问曲线驱动点的圆/椭圆使用范围绘制。隐藏动点不丢失约束，普通曲线不裁剪；不支持的类型和歧义绑定仍沿用现有绘图，并未宣称这些图形的范围已核验。端点以空心/实心和中文文字标明。

tests/motion_domain_tests.cjs共11项通过，新增提前校验与绘图边界性质矩阵。tests/inverse_locus_browser_smoke.cjs使用有出处的2025全国一卷18题确认排除y轴的两个空心标记，并用明确标识的导入图稿夹具验证四分之一圆弧的开闭端点、隐藏驱动点、320像素手机及刷新恢复。与motion_domain浏览器两组通过，已检查手机截图。

云模型与访问策略不变，无新增付费推理。范围绘制不是一般证明；非周期曲线、未知题意条件和多驱动点范围合并仍待扩展。最终完整回归、公开网页、安装版和下载包验收见阶段交接。
