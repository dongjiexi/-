# 0.52.0 验证记录

2026-10-04（北京时间）。本轮是解题流程与云端建图协议修复，不新增自造题或真题答案查表。

## 具体原因及修改

- 合法焦点/顶点没有列在固定坐标表时，被旧协议当成未知引用，整个scene被拒绝。修复共享校验，对F1/F_1/F₁等默认名称绑定画板已有特征；显式同名题设点优先。不存在的焦点、非法参数、循环依赖仍拒绝。
- through_points先于constructions处理，引用后续定义的中点/交点时旧校验失败。现在先建立受控点名表，再把依赖名称转成ID；不把动态点冻结成坐标。
- 云端结果只有整题重试或普通追问，未携带逐问缺图信息。新增solution-review纯数据模块，分别记录作答/图形进度；用户明确点击后携带原题、原解答、待证义务和缺失对象继续推导，仍返回完整分问JSON。
- 新回复尚未完成的问不覆盖此前已作答的问；合并后的总核验降级为待核验。笔记与追问保留。完整旧图稿先备份到独立题本备份记录，容量或格式错误时不改原稿。
- 已有反演引擎接入云端白名单；引用顺序为[中心,原像]，power为有限正数。数值核对包含同射线与距离积，不替代消元或一般性证明。
- 云端多问输出由固定6000改为每问3000、总上限12000；单问仍6000。只是输出上限，不保证模型推导正确，不自动重试或暗中换引擎。
- 输入层按TeX单个参数令牌支持\\dfrac32、\\frac3{2}、\\frac{3}2与\\sqrt5，不把有限小数当精确答案。椭圆上两个已知点联立关于1/a²和1/b²的线性方程，不通过题号或参考答案分发。
- 新增固定底边面积的有界独立模型：行列式的两个符号分支得到两条平行线，逐一与曲线联立并回代，保留所有实候选及竖直解。题面附加条件、复合目标或零面积退化尚未覆盖时不套用。已完整覆盖的题目采用同源答案和画板，原AI图保存为model_scene。
- 另一交点构造排除已有曲线上点，不再默认把已知A标成割线交点。新增second_intersection数据白名单和相切退化检查；名称下标别名仅在唯一对应时绑定，歧义不猜测。
- 定直线代数提示只检查同一步中“解得”声明绑定的显式线性等式，不将弦x=−4与点的轨迹x=−1混为一谈。发现确定冲突时相关问标为partial；该有限检查不认证完整AI证明。

AI有可能继续漏答或误算；输出更长不等于更正确。结构化字段仍只能表达安全构造，不能把任意模型代码执行为作图。新增的两点定椭圆及固定底边面积模型有明确范围，国内云可达性未改变。补全会生成新版图形，原手动图稿完整留在备份中而不是无条件混入另一坐标系。下一步先修剩余真题的建图协议、一般性证明校验及特殊情形，不把生成状态当成证明。
